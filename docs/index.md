# Maths Library

Maths Library es una librería de funciones matemáticas que acepta un número indefinido de argumentos.  

Puedes usarla para sumar, restar, multiplicar y dividir números de manera sencilla.

Ve a la sección "Maths Functions" para ver ejemplos de cada función.
## Instalación

Se recomienda usar Python 3.8 o superior.
